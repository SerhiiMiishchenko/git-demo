Java does not support operator overloading (with one small exception: the + operator is overloaded for String concatenation).
In general, Java avoids operator overloading because it can make code harder to read and maintain — one of Java's main goals was to stay simple and predictable.
Unlike C++, where you can define how operators behave for your custom classes, Java only allows built-in operators to work with built-in types (and String).

The switch statement in Java is a control flow tool that lets you choose between multiple options based on the value of an expression, typically an int, String, enum, or other compatible types.
